# checks/

One script or written procedure per spec or milestone, named to match the spec it proves.

- A check is what makes a milestone's "Done check" real: the reviewer and the milestone-close
  ritual run it and record the result with evidence.
- Name each check to match its spec (spec `foo.md` -> check `foo.sh` or `foo.md`).
- A written procedure is fine where a script is not: state the exact reproduction step and the
  observable pass condition.
